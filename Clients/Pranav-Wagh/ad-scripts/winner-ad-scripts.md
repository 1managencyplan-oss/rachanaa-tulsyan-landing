## PRODUCTION NOTES FOR ALL 5 SCRIPTS

### Hook Rules (first 3 seconds — make or break)
- Always show hook as **on-screen text** — 85% watch on mute
- Hook must create a question or promise in the viewer's mind
- Best hooks from competitor research: Income number, "₹99", "LIVE", Star rating

### Creative Direction
| Script | Visual Recommendation |
|---|---|
| Script 1 (Earn Lakhs) | Pranav on camera + income result screenshot overlay |
| Script 2 (Live Masterclass) | "LIVE" red dot + Pranav teaching on laptop/phone |
| Script 3 (Urgency + Stars) | Static image — bold text, countdown, stars |
| Script 4 (₹99 Masterclass) | Screen recording of store + Pranav voiceover + "Only ₹99" text overlay |
| Script 5 (WhatsApp) | Pranav on camera — casual, direct to camera talk |

### What Makes These "Winner" Scripts
Every angle above was proven by a competitor spending real money for 35–73 days:
- **Script 1** → Maya Preneur's income angle (49 days)
- **Script 2** → Themalluhustler's masterclass angle (scaling 3 ads/week)
- **Script 3** → Zavicodg's urgency + stars angle (73 days = longest winner)
- **Script 4** → Byebyecod's free course angle (35 days)
- **Script 5** → Ecomtree's WhatsApp funnel (4 consistent ads)

### Test Order Recommendation
Launch in this sequence:
1. Script 4 (₹99 Masterclass) — easiest cold audience hook, filters serious buyers, lowers CPL
2. Script 2 (Live Masterclass) — strong lead gen, high intent
3. Script 1 (Earn Lakhs) — income angle for broad reach
4. Script 5 (WhatsApp) — retargeting only
5. Script 3 (Urgency) — use only when batch is actually closing
