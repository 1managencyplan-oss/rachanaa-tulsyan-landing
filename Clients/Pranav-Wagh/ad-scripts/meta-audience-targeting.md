# Meta Ads — Audience Targeting Strategy
**Client:** Zero to Hero Academy | **Goal:** 4,000–5,000 leads/month at ₹60–70 CPL

---

## CAMPAIGN STRUCTURE RECOMMENDATION

### Campaign Type
- **Objective:** Lead Generation (Meta Instant Forms preferred — lower CPL than landing page clicks for cold audiences)
- **Budget:** ₹4–5 lakh/month → ₹13,000–17,000/day
- **Bid Strategy:** Cost Per Result Goal — set at ₹65 to stay within CPL target

---

## AUDIENCE 1 — Broad Marathi-Speaking Maharashtra (Cold)
**Best for:** Scale, lowest CPL at volume

| Setting | Value |
|---|---|
| Location | Maharashtra (all cities + rural) |
| Age | 22–45 |
| Gender | All |
| Language | Marathi |
| Detailed Targeting | OFF (use Advantage+ audience) |
| Placements | Advantage+ (Reels priority) |

**Budget Allocation:** 40% of daily budget

---

## AUDIENCE 2 — Interest-Based (Cold)
**Best for:** Qualified intent signals

| Setting | Value |
|---|---|
| Location | Maharashtra |
| Age | 22–42 |
| Gender | All |
| Interests | Dropshipping, E-commerce, Online Business, Make Money Online, Shopify, Digital Marketing |
| Exclusions | People who already purchased (Custom Audience from pixel) |

**Budget Allocation:** 30% of daily budget

---

## AUDIENCE 3 — Lookalike Audience (Warm-Cold)
**Best for:** Efficiency — mirror existing buyers/leads

| Setting | Value |
|---|---|
| Source | Pixel — LeadGen events OR existing student list (upload CSV) |
| Lookalike % | 1–3% (Maharashtra) |
| Location | Maharashtra |
| Age | 22–45 |

**Budget Allocation:** 20% of daily budget
> Note: Need minimum 100–1000 matched users in source for this to work well

---

## AUDIENCE 4 — Retargeting (Warm)
**Best for:** Converting landing page visitors who didn't fill form

| Setting | Value |
|---|---|
| Source | Website visitors (pixel) — last 30 days |
| Exclusion | Already submitted lead form |
| Ad Creative | Testimonial or objection-handling scripts |
| Frequency Cap | 2–3x per week |

**Budget Allocation:** 10% of daily budget

---

## PLACEMENTS RECOMMENDATION
- **Priority:** Facebook Reels, Instagram Reels (lowest CPL for this category in India)
- **Secondary:** Facebook Feed, Instagram Feed
- **Avoid:** Audience Network (lower intent, wastes budget)

---

## META LEAD FORM SETTINGS
- Form Type: **Higher Intent** (adds review step — reduces fake leads)
- Questions to include:
  1. Name (auto-filled)
  2. Phone Number (auto-filled)
  3. "What is your current occupation?" (dropdown: Student / Job / Business / Housewife / Other)
  4. "Which city are you from?" (short answer)
- Thank You Screen: "आमची team 24 तासांत call करेल. WhatsApp वर message करण्यासाठी खाली click करा." + WhatsApp link

---

## CREATIVE-AUDIENCE PAIRING
| Audience | Best Script |
|---|---|
| Broad Marathi (Cold) | Script 1 (Marathi USP) or Script 3 (Ease) |
| Interest-Based | Script 2 (Income Outcome) |
| Lookalike | Script 4 (Testimonial) |
| Retargeting | Script 5 (Objection Handling) |

---

## SCALING RULE
- If CPL < ₹60 for 3 consecutive days → increase budget by 20%
- If CPL > ₹80 for 2 consecutive days → pause lowest-performing ad set, test new creative
- Check results every Monday + Thursday minimum
